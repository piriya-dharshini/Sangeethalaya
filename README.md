# sangeethalaya_app

A Carnatic Library app to access all songs from krithi's, keerthanai's, bhajans and shlokas for group performances as well as solo performances

## Getting Started

1. Download the sangeethalaya apk from app releases
2. Remove auto blocker in settings of your android mobile
3. Allow the pop-up scanner in your android mobile to scan the application
4. Install the app
5. Sign-up and use the application
