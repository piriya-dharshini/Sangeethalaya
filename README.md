# sangeethalaya_app

A Carnatic Library app to access all songs from kritis, keerthanai's, bhajans and shlokas for group performances as well as solo performances.

## Getting Started

1. Download the Sangeethalaya APK from [Releases](../../releases)
2. If Android blocks the installation, allow installation from the source you're downloading from.
3. Allow Android's security scanner to scan the application if prompted.
4. Install the app.
5. Sign up and start using the application.
